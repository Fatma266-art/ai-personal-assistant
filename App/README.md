# Personal AI Knowledge Assistant

From AI Student to AI Engineer 🚀

AI Knowledge Assistant يقدر يتعامل مع مجموعة من الـPDFs، يفهم محتواها، ويجاوب على أسئلة المستخدم بناءً عليها مع الرجوع للمصادر.

## Project Structure

Ai Assistant/
├── App/
│   ├── notebooks/
│   ├── README.md
│   └── requirements.txt
├── Data/
│   ├── Raw Data/          # PDFs الأصلية
│   └── Processed Data/    # بعد التنظيف والـChunking
└── src/
├── ingestion/         # استخراج النصوص + Chunking
├── embeddings/        # إنشاء الـEmbeddings
├── retrieval/         # البحث في Vector DB
└── llm/               # ربط الـLLM + Prompt
